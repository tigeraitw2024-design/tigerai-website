# 官網接 Google：你要做的事

官網要寄信、要收名單、要讀你的行事曆算出可約時段。這三件事都靠一支小程式
（`Code.gs`）掛在一個 Google 帳號上。下面是你要做的，大概 20 分鐘。

做完把 **四樣東西** 給我，我設定完就會動：

1. Apps Script 的網址（`.../exec` 結尾）
2. 你設的密語
3. 試算表的網址
4. 行事曆 ID（如果你要讓官網避開你自己的私人行程）

---

## 1. 開一個官網專用的 Google 帳號

不要用你的主帳號。這支程式是用「帳號擁有者的身分」在跑，所以它有權限讀寫
那個帳號的**所有信件、試算表、行事曆**。網址萬一外流，波及範圍就只有這個
專用帳號，不會碰到你自己的信。

建議的名字：`tigerai.web@gmail.com` 這類看得出用途的。

**你自己要看得到資料，用「分享」就好，不要共用帳號：**

- 試算表 → 右上「共用」→ 加你的公司信箱
- 行事曆 → 設定 → 與特定使用者共用 → 加你的公司信箱，權限給「變更活動」

這樣所有預約都會出現在你自己的 Google 日曆裡，但程式碰不到你的帳號。

## 2. 開試算表

用專用帳號開一份空白試算表，名字取「官網名單」。

不用自己做標題列，程式第一次寫入時會自己建。

網址長這樣，中間那段就是 ID：

```
https://docs.google.com/spreadsheets/d/【這一段是 ID】/edit
```

## 3. 貼上程式

1. 用專用帳號登入 <https://script.google.com>，按「新增專案」
2. 把編輯區裡原本的東西全部刪掉
3. 把 `Code.gs` 整份貼進去
4. 改最上面那三行：
   - `SECRET` — 隨便打一串長一點的亂碼（這就是你要給我的密語）
   - `SHEET_ID` — 第 2 步那段 ID
   - `CALENDAR_ID` — 留空就用這個帳號的主行事曆，通常留空就好
5. **左邊齒輪「專案設定」→ 時區改成 `(GMT+08:00) Taipei`**

   這一步不做，算出來的可約時段會整個時區歪掉（客戶看到的時間跟你行事曆上
   的時間差八小時）。這是最容易漏的一步。

## 4. 部署

右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」：

| 欄位 | 要選什麼 |
| --- | --- |
| 執行身分 | 我自己 |
| 具有存取權的使用者 | **任何人** |

「任何人」聽起來很可怕，但那只是讓 Cloudflare 打得到。真正的門是你設的那串
密語——沒有密語，任何人打這個網址都只會得到 `bad secret`。

第一次會跳出授權畫面（Google 會說「這個應用程式未經驗證」，因為是你自己寫的），
按「進階」→「前往…（不安全）」→「允許」。

部署完會給你一個 `https://script.google.com/macros/s/.../exec` 的網址。

> ⚠ **以後每次改 `Code.gs` 都要重新部署**：
> 「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本改成『新版本』→ 部署」。
> 只按儲存不會影響線上，這是 Apps Script 最常踩的坑。

## 5. 如果要讓官網避開你自己的私人行程

官網只看得到專用帳號的行事曆。你主帳號上的行程它不知道，所以不會自動避開。

要讓它避開：

1. 用你自己的帳號打開 Google 日曆
2. 左邊你的行事曆 → 三個點 → 「設定和共用」
3. 「與特定使用者或群組共用」→ 加**官網專用帳號**，權限選「查看所有活動詳細資訊」
4. 往下找「整合日曆」→ 複製「日曆 ID」（通常就是你的信箱）
5. 把那個 ID 填進後台「預約時段規則 → 還要避開哪些行事曆」

## 接起來之後會怎麼運作

```
你維護自己的行事曆
    ↓
官網每小時讀一次空檔，照你在後台設的規則（上班時間、一天幾場、
要提前幾小時、兩場之間空多久）算出可約時段
    ↓
客戶在官網上選一個時段、填資料、送出
    ↓
官網當場再跟行事曆確認一次還空著（避免你剛剛自己排了別的事）
    ↓
在行事曆上開一格、寄一張行事曆邀請給客戶
同時寫一列進「官網名單」試算表
    ↓
客戶按「是」 → 後台自動變成「已確認」，這場也進了他的手機行事曆
客戶按「否」 → 後台變成「客戶婉拒」，時段放回去
24 小時都沒按 → 自動取消，行事曆上那一場也撤掉，時段放回去
    ↓
CRM 每兩小時從試算表抓名單進去，標「來源＝官網」
```

交易信（預約確認、訂單通知）官網自己即時寄。行銷信交給 CRM。

## 設定好之後在後台哪裡看

**總覽**那一頁會多兩塊：

- **Google 中繼站**：現在用什麼方式寄信、名單同步開了沒、「測試連線」按鈕
  （只打一下招呼，不會寄信也不會寫試算表）、待送出／送不出去的名單
- **可約時段**：來源是手動還是行事曆、現在有幾個未來的時段、
  「現在重算時段」按鈕（你在行事曆上挪了行程，按一下就馬上反映到前台）

**預約時段規則**那一頁（左邊選單「生意」底下）可以改所有規則，不用找我。

## 免費額度

| 項目 | 免費帳號 | 夠不夠 |
| --- | --- | --- |
| Gmail 寄信 | 每天 100 封 | 預約確認信綽綽有餘 |
| Apps Script 執行 | 每天 90 分鐘 | 每小時重算一次 × 3 秒 = 一天 2 分鐘 |
| 行事曆、試算表 | 沒有實際上限 | — |

寄信超過額度不會掉信：信留在佇列裡，下一輪再試，後台的「待寄出的信」
會看得到。
